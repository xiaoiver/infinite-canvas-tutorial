Add useCanvasShortcuts for focus-scoped undo, redo, select-all, and selection
delete commands. Support Ctrl and Command shortcuts in canvas and sibling React
controls, with readiness guards, nested scope isolation, editable/shadow input
protection, and capture handling to prevent duplicate native commands.

Enable the hook in the bilingual playground and Vite/Next.js starters, and
document error callbacks and custom editor opt-outs.
